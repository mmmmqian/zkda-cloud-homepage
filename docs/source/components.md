# 网站共用部件

- Status: in-review
- Updated in stage: visual
- User approval: selected B + C combination on 2026-08-24

## Decisions

全站共用部件按「C 编辑系统为基础、B 蓝图语言为细节」实现：

- 顶部导航保持已批准入口顺序和 Together AI 式下拉互动，但外壳尺寸按用户 Figma 节点 `2:4` 调整：桌面高 `62px`，Logo 宽约 `125px`、左距约 `36px`，导航字号 `16px`，菜单项横向内边距约 `20px`，登录与主按钮横向内边距约 `24px`。导航背景统一为白色并保留底部细分隔线；“登录 / 立即体验”作为独立按钮组贴右对齐，主 CTA 使用品牌蓝。`901–1240px` 采用更紧凑的字号与间距，`900px` 以下仍进入完整移动菜单。
- `900px` 以下顶栏与展开菜单共用同一个 `62px` 高度基准：顶栏不再额外叠加上下内边距，菜单从顶栏底边开始，避免首页第一项被遮住。菜单 / 关闭按钮的键盘焦点轮廓收进按钮内部并使用品牌蓝，仍清楚可见但不再越出顶栏。
- 用户随后提供 Transform9 移动端收起 / 展开截图作为布局与交互参考。本站只转译结构：有 JavaScript 时收起状态只显示品牌 Logo 与 Lucide 菜单图标；展开后使用覆盖视口的白色菜单层，顶部保留约 `30vh` 呼吸留白，一级入口使用全宽分隔大行，二级内容仍在所属栏目内原位展开；登录与立即体验变为底部 `1:1` 固定操作栏。打开菜单时临时清除首屏入场可能残留在 Header 上的 `transform`，避免 fixed 菜单被限制在顶栏容器；关闭按钮同时固定到视口右上角并提升到菜单层之上，确保展开后始终可见。白色品牌系统、中文入口、页面链接和 Lucide 图标保持本站自己的实现，不复制参考站黑色外观、Logo、文案或代码。收起状态的菜单按钮不显示分割线，点击区域和焦点态保持不变。
- 导航的下拉箭头、移动菜单和关闭图标使用 Lucide 官方 `chevron-down`、`menu`、`x` SVG，固定保存在 `assets/icons/lucide/`；不手绘 UI 图标，也不依赖运行时 CDN。品牌 Logo 与 favicon 继续使用中科达云正式品牌素材，不用通用图标替代。
- 首页首屏保留浅色 WebGL / Canvas 动态数据场，DOM 构图以 Figma 节点 `64:34956` 为静态视觉 Source of Truth：参考画板 `1651×863`，标题距 Hero 顶部约 `78px`、左锚点约 `36px`，使用常规字重、`100px / 122px` 的标题节奏，品牌蓝只用于“全面 智能”；下方约 `356px` 双栏分别呈现“我们是谁：”与“联系我们：”，右栏直接使用 `contact@zhongkedayun.com`。`≥992px` 的 Hero 高度、标题、Lower Grid 与 Pixel Field 使用同一套 width-derived 连续缩放并设置上下限，不再混用 `100svh`；`768–991px` Lower Grid 保持 `50 / 50` 双栏，只压缩 Typography / Padding；`480–767px` Selective Reflow 为单栏，`≤479px` 允许完整 Mobile Recompose。Lower Grid 顶部结构线在所有宽度下 full-bleed；`≥768px` 保留中央竖线，`<768px` 取消并改为横向块分隔。动态仍不承担文字信息。
- 2026-08-28 按用户局部截图移除首屏最底部横向分割线；Lower Grid 顶部结构线继续保留并在 2026-09-08 明确为所有宽度 full-bleed。桌面双栏中央竖向分隔仅在双栏模式保留，Tablet / Mobile 单栏模式改为内容块间横线。
- 鼠标局部揭示使用“实体格 + 独立 Glow + 暖白遮罩”三层分工。2026-08-27 根据用户提供的浅色参考图修正：核心范围内除既定约 18% 缺口外，遮罩必须完整打开；遮罩矩形严格使用单格边界，不再向相邻格扩张和重复擦除，避免格子边缘比中心更亮。根据第二张局部截图继续修正：全屏柔化层降到数据格下方，只柔化环境光；数据格、清晰重绘层与揭示遮罩取消整体缩放，遮罩自身不再使用 CSS Blur，避免浏览器插值形成横向或纵向虚边。随后按用户提出的“中心高清、向外逐步模糊”增加一层受控景深：它位于实体数据格上方、清晰重绘层下方，使用两段宽羽化让中心完全透明、近区轻柔化、远区加强柔化；焦点随既有鼠标惯性坐标移动，并由随机缺口和逐格清晰重绘打散规则轮廓，不形成可见圆形窗口。手机和减少动画模式关闭该层。外围 Glow 和慢速环境模糊继续独立运行，鼠标本身不绘制光晕。
- 品牌 Logo 循环带与首屏共用 `#F9FAFC` 浅色背景。2026-08-27 用户提供 `卡商logo/卡商logo黑色/` 中 12 份黑色 PNG；公开轨道已整组替换，统一显示高度 `35px`，宽度保持每份原文件的自然比例，不拉伸、不裁切。按用户此前要求不显示暂停按钮；鼠标悬停暂停、减少动画静态回退继续保留。
- 公开数据区按 Figma 改为左侧“可核对的规模 & 稳定性”标题与像素插图，右侧展示四组批准事实：`5,000+`、`20+`、`99.9%`、`100+`。Figma 模板中未获批准的占位数字不进入网站。
- 2026-08-27 按用户截图移除“规模与稳定性”整个区块上、下两条横向分割线；上边界同时清除相邻 Logo 循环带的底边线。四组数据内部的面板边界、展开逻辑、图片与文案不变。
- 首页平台能力区以 Figma 节点 `60:34731` 重建为左侧生命周期总览、右侧分层能力卡；前五张标题、序号、正文、颜色与五份节点导出图标逐项对应。用户随后新增第六张“AI 驱动开发 / AutoDev”，使用已确认的本地 AutoDev 循环素材与 `#071326` 深蓝色面。桌面六张卡使用相同的展开高度，未来卡片位于可视区下方，随滚动逐张上移并覆盖前一张，只保留已浏览卡的标题条；当前卡下方的浅色留白随层数逐步减少，直到 06 出现才形成填满固定区域的完整堆叠。移动端六张卡默认完整展开并纵向排列；滚动时后一卡逐张 sticky 覆盖前一卡正文，前一卡只留下标题条，形成随滚动增长的顶部堆叠。每张卡的负向底边补偿与后一张正向顶边补偿保持默认纵向间隔不变，同时让六张卡共享释放边界；因此 06 固定后不会独自滑走，父容器结束时六层一起离场。无 JavaScript 与减少动画时取消 sticky，仅保留六张完整顺序显示。

## Interaction states in visual stage

- Hover：可点击整行入口进行高对比色面反转；不使用位移、缩放或光晕来制造按钮反馈。
- Focus：保留 3px 明确焦点轮廓；颜色反转后文本、说明和箭头仍可读。
- Reduced motion：所有视觉阶段新加的颜色过渡关闭；既有首屏、品牌循环继续使用已验证的静态回退。
- No JavaScript / asset failure：导航、正文、CTA 与所有本地路由仍可用；蓝图 SVG 失败只损失装饰背景。
