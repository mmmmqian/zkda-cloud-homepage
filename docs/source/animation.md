## Decisions

用户希望采用明显的滚动叙事，并参考 Transform9 的互动节奏；具体触发、范围和替代状态尚未进入正式实现阶段。

- 2026-08-24 用户进一步指定 `https://tr9.webflow.io/` 作为交互、过渡和动画的主要参考。真实浏览器自动观察超时，公开页面读取只能确认长页面章节、数据段、品牌循环和连续产品叙事；精确触发、缓动、时长与源码均未形成 Observed 证据。
- 第 7 步优先研究并自主实现：章节进入时的克制显现、页面色面与线稿的连续衔接、长页面段落之间的节奏变化、产品关系与迁移流程的滚动叙事。不会复制参考代码、完整构图或素材。
- 首页首屏的鼠标揭示在视觉阶段按用户明确参数实现：现有惯性坐标同时驱动上层渐进景深，中心保持完全高清，近区通过宽羽化过渡到约 `8px` 柔化，远区再过渡到约 `18px`；局部清晰层仍按数据格和随机缺口显现，因此用户只感受到焦点变化，不会看到一个规则圆形窗口。鼠标离开后焦点保留在最后位置并继续呼吸；手机、粗指针与减少动画模式关闭该景深层，Canvas 或滤镜失败时不影响标题和操作入口。

- 首页首屏后的国产芯片品牌带使用纯 CSS 线性循环，单轮约 32 秒；同一列表复制一份只用于无缝衔接，复制项从辅助技术中隐藏。
- 鼠标停留在品牌带上时暂停，便于阅读；另提供可由键盘和触屏操作的“暂停循环 / 继续循环”原生复选开关，状态切换完全由 HTML / CSS 完成。用户启用“减少动画”后完全停止循环，只显示一份列表并允许横向浏览，同时隐藏不再需要的暂停开关。无 JavaScript 时行为不受影响。
- 当前品牌带属于用户在排版阶段明确要求的可见行为，不代表第 7 步全站动态效果已经批准；滚动叙事、GSAP ScrollTrigger 与其他页面动态仍在后续阶段统一确认。
- 2026-08-26 用户提供 7 秒产品切换录屏。逐帧可确认：标题和网格结构保持不动；旧状态与新状态在同一位置短暂叠合并交叉淡化，没有横向滑入；箭头悬停使用反色反馈。本站据此将产品轮播改为约 520ms 的原位交叉淡化，三个状态继续循环切换；减少动画时取消过渡并瞬时更新，无 JavaScript 时依次显示全部产品。录屏只作为切换行为证据，不复制其中客户、人物、Logo、文案、数据或完整构图。
- 2026-08-27 用户提供平台能力桌面与移动端录屏。桌面逐帧可确认：左侧总结保持固定；右侧六张卡使用相同的展开高度，未来卡片先处于屏幕下方，随滚动逐张上移覆盖前一卡，只留下已浏览卡片的标题条。展开卡高度不随序号变化，因此 01–05 状态下方仍保留逐步缩小的浅色空区，直到 06 出现才由五条历史标题加当前卡填满固定区域。用户随后用移动端截图及录屏第 4–5 秒明确：六张卡默认完整展开并纵向排列，滚动时后一卡逐张覆盖前一卡正文，只留下已经过卡片的标题条形成顶部堆叠；06 与前五卡遵循相同规则，到达第五条历史标题后的固定卡位便停止单独移动，之后完整堆叠作为整体离场。桌面使用原生滚动进度，以约 `620ms` 缓动改变卡片上缘位置；手机端使用 CSS sticky、约 `74px` 的逐层偏移和相互补偿的外边距，使六卡共享释放边界，不依赖点击切换。用户新增的第六张 AutoDev 同样进入两端序列。键盘或点击已出现的桌面标题时滚动到对应状态；减少动画或 JavaScript 失效时取消 sticky、固定与覆盖，六张卡全部完整显示。
