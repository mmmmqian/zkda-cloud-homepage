# 全站颜色、字体与间距

- Status: in-review
- Updated in stage: visual
- User approval: selected B + C combination on 2026-08-24

## Decisions

用户选择「B 工程蓝图 + C 精密编辑系统」组合方向：以 C 作为全站基础视觉，以 B 作为插图与技术细节语言。真实 HTML 已开始应用该组合，不把三张生成效果图当作公开图片素材。

### C｜全站基础系统

- 主背景使用冷灰白纸色 `#F9FAFC`，辅助冷灰纸色 `#F1F3F3`；正文近黑 `#11110F`，边框冷灰 `#C6C9CD`。
- 品牌蓝 `#1B58F4` 用于竖向色面、超大数据、主按钮、索引与关键状态；荧光绿 `#89FF75` 只在深色区域承担极少量信号强调。
- 中文大标题继续使用系统中文无衬线回退，依靠字号、字重、行距和非对称留白建立编辑感；全站英文与普通数字使用 Roboto，01–06、步骤索引、团队编号和发展历程年份等编号类数字使用 Roboto Mono。两款英文字体通过 Google Fonts 官方 CSS 加载，失败时分别回退到系统无衬线与系统等宽字体，不影响中文内容与页面结构。
- 四组公开数据使用超大蓝色数字；正文、说明、索引和分隔线形成明确的印刷层级，不采用圆角卡片、渐变按钮或玻璃表面。
- 2026-08-25 用户在 Figma 正式首页基线中只调整首屏、卡商 Logo 循环和公开数据区：这三处改用更冷的浅灰白 `#F9FAFC`；首屏以近黑超大标题和品牌蓝重点词形成两行主叙事，数据区使用白色标题栏、品牌蓝图像主面与三档深蓝数据面。2026-08-26 用户再次指定历史节点 `2:53`（现由 `64:34956` 取代） 严格复核，标题中文使用苹方常规字重，英文 `AI` 遵守全站 Roboto 规则；主色为近黑 `#11110F`、品牌蓝 `#1B58F4`，价值短句不再使用绿色或蓝色。其他首页区块和所有内页继续使用已批准的 B+C 系统，不随本次同步改变。
- 2026-08-26 用户指定 Figma 节点 `2:4` 作为导航布局尺寸来源，并进一步明确导航背景为白色。桌面导航统一为 62px 高、16px 字号、125px Logo 与品牌蓝主按钮；900px 以下保留既有移动菜单。UI 图标来源统一为 Lucide 官方 SVG，不自行绘制。
- 产品关系区按用户 2026-08-26 提供的 Figma 节点改为冷白 `#F9FAFC` 产品轮播：超大近黑标题、细分隔线、品牌蓝链接与能力竖线、左侧浅色工程插图构成主要层级。箭头 Hover / Focus 使用品牌蓝反转，产品详情链接保持清晰焦点，不使用发光卡片。
- 2026-08-26 用户进一步指定产品体系节点 `33:30855`、`38:32066`、`38:32238` 与移动节点 `47:34237`。首页原深色三行列表由浅色三状态轮播取代。首轮只同步版式和既有内容；用户随后明确要求严格采用设计稿布局与文案，因此三个桌面状态的说明、能力标签及 `99%`、`500K+`、`10K+`、`23`、`99.9%` 已作为用户提供文案回写。移动节点只用于响应式构图，避免采用其混入的其他状态内容。

### B｜工程蓝图细节

- 详情页首屏和迁移占位媒体使用本站原创 SVG 蓝图线稿：结构线、连接节点、测量刻度与少量状态点；不复制效果图中的具体线稿或参考网站素材。
- 蓝图只作为次级信息层，不与标题争夺阅读顺序；手机端降低可见范围并保留足够纯色背景。
- 插图不承载事实、产品参数或交互操作，加载失败时文字内容与页面结构仍完整。

### Transform9 参考边界

- 用户指定 `https://tr9.webflow.io/` 作为过渡、滚动和交互节奏的主要参考。2026-08-24 真实浏览器自动观察再次超时；公开页面读取只确认长页面章节、数据段、品牌循环和连续产品叙事，不能证明精确缓动、触发点或源码。
- 第 6 步只实现静态视觉和基础 Hover / Focus 状态；滚动过渡、GSAP ScrollTrigger 与复杂交互保留到第 7 步，在真实浏览器中重新观察或依据用户补充录屏确认后实现。
- 用户已在第 6 步为平台能力区补充 Figma 节点与桌面 / 移动录屏，因此该区可提前实现其局部滚动行为；这不代表第 7 步其余全站动态已获批准。Figma 前五层色面为 `#0033CC / #00269B / #001A6A / #000D39 / #020801`，用户新增的 AutoDev 第六层使用 `#071326`；正文与图标使用白色，外壳使用 `#F9FAFC`。
- 不复制参考站代码、图片、Logo、文案或完整构图。
